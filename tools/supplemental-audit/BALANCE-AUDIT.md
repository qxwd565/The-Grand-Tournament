# 대 마상시합 한국 출시·변경 이력 감사

범위: qxwd565/The-Grand-Tournament의 수집 가능 카드 132종과 생성 카드·선택지·영웅 능력 20종, 총 152종. 다른 확장팩은 이번 변경에 포함하지 않았습니다. 비교 기준 원격 HEAD는 d04048e30e0ac075b5961e0198c5576d38fd828d입니다.

## 저장 형식

- `data/<ID>.json`: 기존 필드를 유지하는 schemaVersion 2. `card`는 최초 사용 가능일 기준 상태, `card.patches`는 날짜순 변경 필드입니다.
- `cards.json`: 현재 상태. `render.json`: 현재 상태와 역방향 기간별 차이. 루트 `history.json`: 기존 호환 인덱스입니다.
- 기존 `data/history.json`의 date-first-delta 형식은 유지하되 같은 canonical 카드에서 재생성합니다. 최초 날짜에는 전체 카드 상태, 이후에는 바뀐 필드만 기록합니다.
- 원래 날짜별 집계는 현재값을 출시 시점에 복사한 임시본이었습니다. 원본 바이트는 `tools/original-date-first-history.json`에 보존했습니다. 이 파일은 서비스용 역사 스펙이 아니라 감사 증거입니다.
- `nativeTags`, `nativeRawText`, 원시 문구 관측은 수정하지 않습니다. 현재 설치 데이터의 태그를 과거 수치로 해석하지 마세요. 원화·황금 카드 자료도 변경하지 않습니다.
- 표시 문자열 개행은 `<br></br>`로 통일했습니다. JSON 구조 개행과 원시 증거는 예외입니다.

## 최초 사용 가능일

- 149종은 한국 정식 출시인 **2015-08-25**. 3.0 클라이언트 사전 추가일, 공개일, 체험 난투·투기장 개방일이 아닙니다.
- 판드랄 합성 변신 `OG_044c`는 고대 신의 속삭임 한국 출시 **2016-04-27**.
- 죽음의 기사 강화 영웅 능력 `HERO_11bp2`와 생성 구울 `HERO_11bp2t`는 직업이 실제 개방된 **2022-12-07**. 25.0 사전 패치일과 다릅니다.
- `AT_063t` 공포비늘은 접미사가 t여도 수집 가능 카드입니다.

## 주요 검증·수정

총 104개 날짜별 이벤트를 78종에 기록했습니다. 이 수는 순수 밸런스 너프·상향 건수가 아니라 수치, 효과, 직업, 종족, 계열, 선택지, 키워드와 확인된 이름 변경의 합계입니다. 기존 개별 카드에는 forward 패치가 없었고 별도 날짜별 집계에는 일부 분류 이력만 있었습니다.

- 2016: 네루비안 생성 토큰 비용 3→4, 투스카르 토템지기의 기본 토템 제한.
- 2017~2019: 얼음 광전사 정령, 공포마 지연 재소환, 네루비안 잠복의 비용·이름·뽑을 때 시전, 북해 크라켄 야수, 아비아나 9→10, 선택지 UI·비용·이름.
- 2021~2022: 핵심 세트 사전 상향, 주문 계열, 강타와 전투마 조련사 상향, 언데드 분류.
- 2023: 신성한 용사·선조의 지혜, 멧돼기 마법사 분류, 27.2의 수집 가능 27종과 아눕아락 생성 네루비안, 27.4.2의 어둠의 거래·작고 사악한 창기사·파괴의 정기.
- **어둠의 종복**은 2023-08-23 비용 4→5와 전투의 함성 추가. 원본 세트 생명력은 4로 남았으므로 **2023-09-07** 실제 서버 수정에서 4→5를 따로 기록했습니다. 27.2.2의 수집품 화면 수정과 구분했습니다.
- 2024~2026: 심판관 트루하트 5마나 6/4, 드레나이 종족, 천공의 교감 4→5.
- 북해 크라켄 종족은 11.4의 한국 **2018-07-11**, 드레나이는 30.6에 없다가 31.0에 추가되어 한국 **2024-10-30**입니다. 확장팩 출시일로 늦추지 않았습니다.

정확한 날짜·원문·출처와 카드별 이벤트는 `tools/tgt-release-audit.json`, 독립 조사 근거는 `tools/tgt-independent-review.json`에 있습니다.

## 검증 한계

- 수치·타입·직업·종족·계열을 선택된 클라이언트 빌드들과 대조했습니다. 모든 빌드, 일시적인 사용 금지, 내부 엔진·버그 수정 이력까지 전수 완결했다고 주장하지 않습니다.
- 58종은 API의 초기 표시 이름/문구가 출시 원문과 완전히 일치하지 않아 미확정 범위를 남겼습니다. 실제 효과 변경일은 확인해도 그 사이 모든 쉼표·띄어쓰기·문구 변경일까지 단정하지 않습니다. 모든 카드의 `initialSpecStatus`는 `partially_verified`입니다.
- 살아있는 뿌리는 한국 2020-03-27에 실제 특급 보석 오류가 발생했고 17.0.0.44582에서 일반으로 복구되었습니다. 한국 복구 날짜가 미확정이라 canonical 희귀도 두 이벤트는 보류했습니다. 한국3/29에는 보라 보석과 정상40/5 가루 비용이 함께 관찰되어 서버 가루 수정과 클라이언트 표시 복구를 구분합니다. 구간·원문·출처는 `tools/tgt-known-unmodeled-intervals.json`에 있습니다. 두 드루이드 선택지의 일시적인 희귀도 태그 누락도 날짜 미확정입니다.
- 악마의 기운의 구형 SPELL/DEMON 태그는 악마 감지의 잘못된 드로우 상호작용에 실제 영향을 주었으며 3.1 한국 2015-09-30 제거로 기록했습니다. 주문이 하수인이 되거나 하수인 종족 표시판을 가졌다는 뜻은 아닙니다. 살아있는 뿌리의 선택지 두 개와 묘목의 초기 CLASS 미기재→드루이드 경계도 정확한 날짜 미확정으로 보존했습니다.
- 천공의 교감 **2026-04-03**은 공식 순차 배포 안내, 한국 일정과 당일 적용 반응을 종합한 날짜입니다. 한국 서버 배포 완료 시각을 직접 확인한 것은 아닙니다. 아비아나 **2018-10-19**도 공식 태평양 일정과 동시대 실제 적용 자료를 교차검증한 결과이며 한국 서버 운영 공지 직접 확인과 구분합니다.
- 무기 원본의 DURABILITY→HEALTH 태그 전환은 동일 내구도의 내부 표현 변경입니다. 실제 밸런스 패치로 만들지 않았습니다.
- 현재 최신 게임 스펙은 변경하지 않았습니다. 출시일 메타데이터와 표시 개행만 추가·정규화했습니다.
